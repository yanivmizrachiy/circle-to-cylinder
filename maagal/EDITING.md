# עריכת חוברת „מעגל” — מדריך מקומי

> **הסמכות היחידה לכללי כתיבה, מתמטיקה ועיצוב היא [`../RULES.md`](../RULES.md).**
> `manifest.json` שבתיקייה זו הוא מנגנון ניתוב מקומי בלבד. הוא אינו SSOT של הפרויקט ואינו מגדיר כללי עיצוב.
> סדר הפרסום של החוברת כולה נקבע רק ב־[`../content-manifest.json`](../content-manifest.json).

## איפה עורכים

| צורך | קובץ |
|---|---|
| תוכן עמוד תרגול | `source/original-88/page-*.html` |
| תוכן תרגול נוסף | `source/targilim/g8-*.html` |
| תוכן מקור רשמי | `source/bbb/עמוד-*.html` — רק בשינוי מבוקר ובהתאם ל־`RULES.md` |
| מיפוי עמוד מעגל → קובץ מקור | `manifest.json` → `segments` |
| עיצוב legacy של מעגל | `styles.css` |
| עיצוב עמודי bbb | `styles/a4-base.css` + `styles/topics/bbb-geometry8.css` |
| תצוגת מעגל מקומית | `index.html` |

`page-N.html` הם loaders זהים. **לא עורכים אותם ידנית.** הם קוראים את `manifest.json`, מאתרים את ה־segment המתאים וטוענים את קובץ המקור.

## שינוי סדר או מספר עמודים

- שינוי תוכן שמופיע בתוך אותו מספר עמוד: עורכים רק את קובץ המקור.
- שינוי הניתוב בתוך 99 עמודי המעגל: עורכים `manifest.json` → `segments`.
- הוספה או הסרה של עמוד שמשנה את מספר העמודים: מעדכנים גם את `content-manifest.json`, את ה־PDF ואת בדיקות ה־QA, בהתאם ל־`RULES.md`.

## לפני סיום

בודקים שה־JSON ב־`manifest.json` תקין, שכל `page-N.html` נטען, שאין עמוד חסר, שאין חריגת A4, ושהשינוי עומד ב־`RULES.md`. אין להחזיק כאן עותק נוסף של כללי העיצוב או הניסוח.
