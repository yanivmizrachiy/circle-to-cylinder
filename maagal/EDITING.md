# איך עורכים את חוברת "מעגל" — מדריך מהיר

החוברת בנויה בארכיטקטורה **מונחית-מניפסט**: רשימת-עמודים אחת (`manifest.json`) קובעת מה מופיע בכל עמוד ובאיזה סדר, והתוכן עצמו יושב בקבצי-מקור נפרדים. כך עריכה, הוספה או שינוי-סדר נעשים במקום אחד וברור — בלי לשכפל קבצים.

## מפת הקבצים

| נתיב | תפקיד | מתי לגעת |
|---|---|---|
| `manifest.json` | **סדר העמודים** ומיפוי עמוד→מקור (`segments`) + כללי-העיצוב | לשנות סדר, להוסיף/להסיר עמוד, להגדיר SSOT |
| `source/bbb/עמוד-*.html` | **שאלות משרד החינוך הרשמיות** (תקן-זהב) | כמעט אף פעם — תוכן רשמי, לשמור נאמנות |
| `source/original-88/page-*.html` | עמודי תרגול (legacy) | לערוך שאלה/מספר/טבלה בעמוד תרגול |
| `source/targilim/g8-*.html` | נספח תרגול נוסף | כנ"ל |
| `styles.css` | עיצוב עמודי ה-legacy + הפוטר המחוזי + SSOT | שינוי מראה גורף לעמודי התרגול |
| `styles/a4-base.css` + `styles/topics/bbb-geometry8.css` | עיצוב עמודי ה-bbb הרשמיים | שינוי מראה לעמודי התקן |
| `index.html` | המציג האינטראקטיבי | ניווט/תצוגה |
| `page-N.html` | **טוען** (loader) — קורא את המניפסט ומושך את המקור הנכון | אף פעם; זהה לכל העמודים |

## איך העמודים נבנים
כל `page-N.html` הוא טוען קטן וזהה. בזמן פתיחה הוא:
1. קורא את `manifest.json`, מוצא את ה-`segment` שמכסה את עמוד N.
2. לפי `kind` מושך את המקור: `bbb` → `source/bbb/עמוד-*`, `original` → `source/original-88/page-*`, `targilim` → `source/targilim/*`.
3. מזריק את מספר העמוד הנכון ומציג.

כלומר: **כדי לשנות סדר** — ערכו את `segments` ב-`manifest.json`. **כדי לשנות תוכן** — ערכו את קובץ-המקור המתאים.

## כללי SSOT (אחידים לכל הפרויקט)
עמודי ה-bbb כבר עומדים בהם; עמודי ה-legacy יושרו אליהם:
- **סמן משימה** = נקודה כחולה (`<span class="qmark">`), לא מספור.
- **כפל** = `×` (לא `·`). מפריד-רשימה = `•`.
- **קוטר** = המילה "קוטר", לעולם לא הסימון `d`. (שימו לב: `d="..."` בתוך SVG הוא מאפיין גרפי — לא לגעת!)
- **כותרות-טבלה** = מונחים אמיתיים (רדיוס/קוטר/היקף/שטח/גובה/נפח), לא "נתון/מבוקש/תשובה".
- **שרטוטים** = בלי מספרי-מידה על הציור; המידות בטקסט/בטבלה. על הציור רק אותיות (A,B) ומשתנים (r,h).
- **אזור פתרון** = תווית "תרגילים:" → רשת-משבצות (`.work-grid`) → משפט-השלמה עם יחידה.

## הפוטר המחוזי הקבוע
כל עמוד מסתיים בפוטר (נוסח מחייב — **אין לשנות מילה**):
```html
<footer class="gz-footer">
  <div class="f1">יניב רז - מדריך מחוזי חט"ב בעיר ירושלים</div>
  <div class="f2">הדרכה במחוז ירושלים והעיר ירושלים - מנח"י, בהובלת איילת קריספין</div>
</footer>
```
קו כחול `#1d4ed8` edge-to-edge מעל הקרדיט. הסגנון ב-`styles.css` (legacy) וב-`a4-base.css` (bbb).

## להוסיף / לסדר-מחדש עמודים
- **סדר**: שנו את `segments` ב-`manifest.json` (כל segment: `from`,`to`,`kind`,`sourceStart`/`source`).
- **עמוד חדש**: הוסיפו קובץ-מקור ב-`source/...` והרחיבו segment מתאים (ועדכנו `pageCount`).

## אימות לפני "סיום"
רנדרו את העמודים (Chromium) ובדקו: התאמת A4 (בלי חריגה/גלילה), אפס `·`/`d`-טקסטואלי/מספור/כותרות-גנריות, ונוכחות הפוטר. התוכן הרשמי (bbb) לא משתנה — רק מיקום/עיצוב סביבו.
