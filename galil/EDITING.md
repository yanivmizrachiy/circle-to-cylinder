# עריכת חוברת „גליל” — מדריך מקומי

> **הסמכות היחידה לכללי כתיבה, מתמטיקה ועיצוב היא [`../RULES.md`](../RULES.md).**
> הקבצים בתיקייה זו הם מימוש מקומי בלבד. הם אינם מקור־אמת מתחרה.
> סדר הפרסום של החוברת כולה נקבע רק ב־[`../content-manifest.json`](../content-manifest.json).

## שלושת הקבצים המקומיים

| קובץ | תפקיד |
|---|---|
| `page-N.html` | תוכן עמוד N כ־JSON |
| `styles.css` | מימוש העיצוב של עמודי הגליל legacy |
| `render.js` | מנוע שממיר את נתוני העמוד ל־HTML |

כלל עבודה: **תוכן → `page-N.html` · מראה → `styles.css` · התנהגות → `render.js`.**
כל החלטת עיצוב או ניסוח נלקחת מ־`RULES.md`; אין לשכפל אותה כאן.

## מבנה עמוד

```html
<script type="application/json" id="page">
{ "n": 26, "title": "נוסחת נפח הגליל", "anchor": "...", "tasks": [ ... ] }
</script>
```

סוגי הבלוקים הנתמכים ב־`render.js` כוללים: `note`, `table`, `bank`, `fill`, `choice`, `choices`, `fig`, `figrow`, `think`, `solve`, `explain`, `html`, `cols`.

דוגמה לאזור פתרון:

```json
{ "t": "solve", "sentence": "נפח הגליל הוא __ π סמ״ק.", "grid": "lg" }
```

## שינוי מספר עמודים

כרגע מקטע הגליל legacy מכיל 39 עמודים. אם מוסיפים או מסירים עמוד, לא מעדכנים רק preview מקומי: חייבים לעדכן גם את `content-manifest.json`, את ה־PDF ואת בדיקות ה־QA לפי `RULES.md`.

## לפני סיום

בודקים JSON תקין, רינדור A4 ללא overflow, נכסים תקינים, התאמה לכללי `RULES.md`, ושסדר הפרסום הראשי לא השתנה בטעות.
