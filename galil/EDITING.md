# איך עורכים את חוברת "גליל" — מדריך מהיר

החוברת בנויה בארכיטקטורה **מונחית-נתונים** (data-driven) עם **מקור-אמת יחיד** (SSOT).
המשמעות המעשית: כדי לשנות תוכן או עיצוב אתם נוגעים ב**מקום אחד בלבד**, והשינוי חל נכון ותקני על כל העמודים — בלי לצוד בעשרות קבצים, ובלי להישבר מול כללי-העיצוב.

## שלושת הקבצים שחשוב להכיר

| קובץ | תפקיד | מתי לגעת |
|---|---|---|
| `page-N.html` | **התוכן** של עמוד N — אי-נתונים אחד בפורמט JSON | לשנות שאלה, מספר, טבלה, שרטוט בעמוד מסוים |
| `styles.css` | **כל העיצוב** — צבעים, מרווחים, גופנים, משבצות, פוטר (משתני `:root`) | לשנות מראה גורף לכל החוברת |
| `render.js` | **המנוע** — הופך את ה-JSON ל-HTML תקני ואוכף את כללי ה-SSOT | כמעט אף פעם; רק להוספת סוג-בלוק חדש |

> כלל אצבע: **תוכן → `page-N.html`. מראה → `styles.css`. התנהגות → `render.js`.**

## לשנות תוכן בעמוד (הנפוץ ביותר)

פִתחו את `page-N.html`. בתוכו בלוק אחד:

```html
<script type="application/json" id="page">
{ "n": 26, "title": "נוסחת נפח הגליל", "anchor": "...", "tasks": [ ... ] }
</script>
```

ערכו את ה-JSON ושמרו. רעננו את העמוד — זהו. (אין בנייה/קומפילציה.)
לדוגמה מלאה ומאומתת ראו את `page-26.html`.

### מה אסור לכתוב (המנוע כבר מטפל בזה)
- **מספרי-משימות** — המנוע מוסיף נקודה כחולה אוטומטית. אל תכתבו "1." / "2.".
- **כפל `·`** — כתבו `×` (גם אם תכתבו `·`, המנוע ימיר אותו).
- **קוטר כ-`d`** — כתבו את המילה **"קוטר"**. (המנוע מתריע בקונסול אם מזהה `d` חשוד.)
- **תיבת "X = ____" ריקה** — השתמשו בבלוק `solve` (רואים למטה).
- **פוטר/כותרת** — נוספים אוטומטית מ-`title` ו-`n`.

## אוצר סוגי-הבלוקים (`"t"`)

| t | שימוש | שדות |
|---|---|---|
| `note` | פסקה חופשית | `text` |
| `table` | טבלה | `head:[...]`, `rows:[[...]]` (תא `""` = ריק להשלמה) |
| `bank` | מחסן מילים/קשרים | `words:[...]`, `plain?` |
| `fill` | משפטי-השלמה | `lines:["A הוא ___."]` ( `___` → שדה) |
| `choice` | בחירה אופקית (גלולות) | `opts:[...]`, `circle?` (מוסיף "הקיפו:") |
| `choices` | רשימת טענות עם תיבת-סימון | `opts:[...]` |
| `fig` | שרטוט יחיד | `svg`, `cap?` |
| `figrow` | שורת שרטוטים | `cols?`, `cards:[{svg,id?,cap?}]` |
| `think` | תיבת חשיבה | `html` |
| `solve` | **אזור פתרון תקני** | `lab?`("תרגילים:"), `sentence?`(`__`→קו), `grid?`:`sm`/`lg` |
| `explain` | אזור הסבר | `lab?`("הסבירו:"), `grid?` |
| `html` | פתח-מילוט ל-markup מדויק | `html` |
| `cols` | פריסת עמודות | `n?`, `cells:[[...],[...]]` |

### דוגמת בלוק פתרון תקני
```json
{ "t": "solve", "sentence": "נפח הגליל הוא __ π ס\"מ³.", "grid": "lg" }
```
מפיק: תווית "תרגילים:" → רשת-משבצות → משפט-השלמה עם קו וביחידה. (SSOT מלא, אוטומטי.)

## לשנות עיצוב גורף

ב-`styles.css`, בראש הקובץ, בלוק `:root` עם כל המשתנים. דוגמאות:
- צבע כחול ראשי לכל החוברת → `--blue`
- גובה/צפיפות משבצות אזור-העבודה → `--cell`
- טקסט הקרדיט בפוטר → `--credit`

שינוי משתנה אחד = שינוי בכל 39 העמודים, תקני ואחיד.

## להוסיף / לסדר-מחדש עמודים
- **עמוד חדש**: צרו `page-N.html` (העתק-הדבק מ-`page-26.html`, החליפו את ה-JSON), ועדכנו `const total=` ב-`index.html`.
- **סדר**: סדר העמודים נקבע לפי מספרי הקבצים; המציג (`index.html`) והבנייה ל-PDF עוברים `page-1..total`.

## תצוגה והפקה
- מציג אינטראקטיבי: `index.html` (גלילה/עמוד-בודד; טוען כל `page-N.html` ב-iframe).
- PDF מאוחד: נבנה ע"י סקריפט הרינדור (Chromium) שמצרף את כל העמודים.
