# circle-to-cylinder — חוברת עבודה במתמטיקה (מעגל → גליל → חרוט)

חוברת A4 בעברית (RTL), **אתר סטטי** ב-GitHub Pages — בלי בנייה, בלי Node, בלי תלויות.

🔗 **אתר חי:** https://yanivmizrachiy.github.io/circle-to-cylinder/
📏 **מקור-האמת המחייב:** [RULES.md](RULES.md) — קראו ראשון.

## מבנה
- `index.html` — המציג הראשי: כל החוברת ברצף גלילה אחד (iframes, A4, התאמה לרוחב, ניווט מעגל/גליל/חרוט).
- `maagal/` — מעגל, 99 עמ׳ · ארכיטקטורה מונחית-מניפסט (`page-N.html` loader → `manifest.json` → `source/`).
- `gold/` — עמודי הזהב הקנוניים: גליל 1–7 + חרוט (8) + `styles.css`.
- `galil/` — גליל, 39 עמ׳ · ארכיטקטורה מונחית-נתונים (`page-N.html` = JSON, `render.js` = מנוע, `styles.css`).
- `.nojekyll` — הגשה סטטית.

סדר בחוברת: מעגל 1–99 · גליל-זהב 100–106 · גליל 107–145 · חרוט-זהב 146.

## עריכה עם GPT — התחילו כאן
כל חוברת כתובה כך ש**עריכה נעשית במקום אחד ברור**, בלי לשכפל קבצים:

| רוצים לשנות | פִתחו | מדריך מלא |
|---|---|---|
| תוכן עמוד **גליל** (שאלה/טבלה/שרטוט) | `galil/page-N.html` — ערכו את ה-JSON | [galil/EDITING.md](galil/EDITING.md) |
| תוכן עמוד **מעגל** | קובץ-המקור ב-`maagal/source/...` (לפי ה-`segment` ב-manifest) | [maagal/EDITING.md](maagal/EDITING.md) |
| **סדר** עמודי מעגל / הוספה-הסרה | `maagal/manifest.json` → `segments` | [maagal/EDITING.md](maagal/EDITING.md) |
| מראה גורף (צבעים/גופן/משבצות) | `styles.css` של אותה חוברת (`:root`) | שני המדריכים |

> `maagal/page-N.html` הם **loaders** זהים — לעולם לא עורכים אותם ידנית.

## כללי ברזל (SSOT מקוצר — המלא ב-RULES.md)
- **כפל = `·`** (נקודה אמצעית), לעולם לא `×`. חילוק = `÷`.
- **קוטר** נכתב במילה — לעולם לא האות `d` (בטקסט; `d="…"` בתוך SVG הוא מאפיין גרפי — לא נוגעים).
- **אין מספור** לשאלות/סעיפים — נקודה כחולה מימין לכיתוב.
- **שרטוטים** בלי מספרי-מידה על הציור; המידות בטקסט/בטבלה.
- **פוטר מחוזי** קבוע בתחתית כל עמוד (נוסח מחייב — אין לשנות מילה).
